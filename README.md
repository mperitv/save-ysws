### You Ship You Save 💖
Yep you read that right: you save the code, you save the wishes.   
### Here's how it works:  
#### You Ship:  
Ship a hardware or software project inspired by dreams or wishesYou can make a dreamy website,
a game set in a dream, a robot which wishes good luck when you open your IDE!  
#### We Ship:   
We donate to Make-A-Wish Foundation. Make-A-Wish is a charity that helps children with critical
illnesses by making their wishes come true! There are many Make-A-Wish branches around the world
so you can choose your country's branch (or the country of your choice) and help children's dreams
come true especially for the children in that country. And if there is no branch in that country
there is an international one so it's not a problem!! A certificate of participation!You ship
a project to help kids to feel like they're in a dream!
